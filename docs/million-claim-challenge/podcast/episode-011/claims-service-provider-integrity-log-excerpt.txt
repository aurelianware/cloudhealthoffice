## Note on this environment

Both pods are independent — this local cluster's messaging configuration auto-resolves to
InMemoryMessageBus (no Service Bus connection string configured), so each pod's
SubscriptionHostedService only ever processes claims submitted to that same pod. The 4/6
split above reflects the load balancer's distribution across the two claims-service replicas
during the run, not any correctness property of the stage itself.
