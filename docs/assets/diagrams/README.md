# Diagram Assets

Use this directory for generated or exported diagrams that complement Mermaid
diagrams in the docs.

Prefer Mermaid in Markdown when the diagram should remain source-reviewable and
render directly in GitHub. Use image assets only when the diagram needs layout or
visual treatment that Mermaid cannot provide.

Do not include confidential architecture diagrams, customer-specific topology,
private network details, credentials, or PHI.
