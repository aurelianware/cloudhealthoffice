# Screenshot Assets

This directory is for documentation screenshots and placeholders.

Rules:

- Use synthetic data only.
- Do not include PHI, real member data, real claim data, tenant secrets, tokens,
  private URLs, or customer identifiers.
- Prefer PNG files with descriptive names.
- Keep screenshots tied to a doc, article, benchmark packet, or issue.
- If a screenshot supports a benchmark claim, include the run date, commit SHA,
  and source document in the surrounding documentation.

Suggested folders:

- `dashboard/`
- `claim-viewer/`
- `sentinel/`
- `fhir-explorer/`
- `metrics/`
- `claims-timeline/`
- `batch-processing/`
- `deployment/`
- `architecture/`

Episode-specific benchmark screenshots live with their evidence packet under
`docs/million-claim-challenge/podcast/episode-*/screenshots/`.
