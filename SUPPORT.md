# Support

CloudHealthOffice is source-available software under BSL 1.1. Public support is
best-effort and centered on reproducible technical issues.

## Where To Ask

- Questions and design discussion: [GitHub Discussions](https://github.com/aurelianware/cloudhealthoffice/discussions)
- Bugs: GitHub issues, with reproduction steps and sanitized logs.
- Security vulnerabilities: follow [SECURITY.md](SECURITY.md), not public issues.
- Documentation fixes: pull requests are welcome.

## What To Include

For bugs or setup problems, include:

- Operating system and architecture.
- Docker Desktop or Kubernetes version, if relevant.
- Command used.
- Expected behavior.
- Actual behavior.
- Sanitized logs.
- Commit SHA or branch.

Do not include PHI, production credentials, real tenant details, real claim data,
or private endpoint URLs.
