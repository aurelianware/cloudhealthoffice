# Benefit plan templates

State program benefit plan templates (Medicaid, CHIP), one JSON file per program and population, under a folder per state. benefit-plan-service loads them at startup and serves them at `/api/v1/plans/templates`. Format, status values and the Texas set are described in [docs/integration/STATE-PROGRAM-BENEFIT-TEMPLATES.md](../../docs/integration/STATE-PROGRAM-BENEFIT-TEMPLATES.md).
