# Discussions Guide

Use GitHub Discussions for questions and design conversation that do not yet
need a concrete issue or pull request.

Good discussion topics:

- Understanding healthcare payer workflows.
- Benchmark interpretation and reproducibility.
- Architecture tradeoffs.
- Proposed ADRs.
- Documentation gaps.
- Deployment experience reports using sanitized details.

Please avoid:

- Posting PHI, production logs, credentials, or customer-specific data.
- Asking maintainers to debug a private production environment in public.
- Treating planned capabilities as completed behavior.

When a discussion becomes actionable, create an issue or pull request and link
back to the discussion for context.
