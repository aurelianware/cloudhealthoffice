# Validation errors the HL7 validator currently reports over conformance/golden/,
# recorded by scripts/interop/fhir-validate.sh. One "golden: error" line each.
#
# A line belongs here only with a reason: a profile CHO has not reshaped onto yet,
# or a check that needs a terminology server the run deliberately does without.
# Never add a line to make the build green.
#
# The script fails on an error that is not here AND on a line here that no longer
# occurs, so this file stays honest as the projections are reshaped.

# ── CHO-local extension canonicals are not resolvable ─────────────────────────
# FHIR R4 Claim and Encounter have no header-level element for the CMS place of
# service (837 CLM05-1), so both projections carry it as an extension under a
# urn: canonical. A urn: can never be dereferenced, so the validator cannot read
# the definition and reports the extension as not allowed.
#
# Not a wording problem: either CHO publishes a StructureDefinition at a
# resolvable https canonical, or the element moves to where the profiles put it.
# The CARIN BB non-financial ExplanationOfBenefit carries place of service in
# item.location, which is the direction the Provider Access reshape takes, so
# this is held open rather than papered over.
claim-as-billed: Claim.extension[0]: Error - The extension urn:cho:StructureDefinition:claim-place-of-service could not be found so is not allowed here
encounter: Encounter.extension[0]: Error - The extension urn:cho:StructureDefinition:encounter-place-of-service could not be found so is not allowed here

# ── denial reasons are not yet X12 CARCs (gap G-17) ───────────────────────────
# PDex binds adjudication.denialreason.reason to the X12 Claim Adjustment Reason
# Codes required. CHO's authorization store carries its own reason vocabulary
# (urn:cho:pa-denial-reason), and no mapping to CARCs exists yet. This is the
# same thing gap G-17 records in docs/epa-gap-matrix.md, and it is why the
# Patient Access prior-authorization scenario stays PARTIAL.
prior-authorization-eob: ExplanationOfBenefit.item[1].adjudication[1].reason: Error - None of the codings provided are in the value set 'X12 Claim Adjustment Reason Codes - Remittance Advice Remark Codes' (http://hl7.org/fhir/us/davinci-pdex/ValueSet/X12ClaimAdjustmentReasonCodesCMSRemittanceAdviceRemarkCodes|2.1.0), and a coding from this value set is required) (codes = urn:cho:pa-denial-reason#NOTMEDNEC)
