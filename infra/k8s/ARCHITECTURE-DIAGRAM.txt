1. ✓ Kubernetes Cluster (AKS, GKE, EKS, etc.)
2. ✓ kubectl configured
3. ✓ Helm 3 installed
4. → NGINX Ingress Controller (helm install)
5. → cert-manager (kubectl apply)
6. → DNS A records configured and propagated
7. → Cloud Health Office ingress resources deployed
8. → Wait for TLS certificates to be issued (1-3 minutes)
9. ✓ Access via https://cloudhealthoffice.com
