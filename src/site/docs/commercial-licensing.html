Commercial Licensing

Cloud Health Office is licensed under the Business Source License 1.1 (BSL 1.1). This is a source-available license — not open source. Full source access is provided, but production use requires a commercial license from Aurelianware, Inc.

Overview

BSL 1.1 gives you full access to the source code with one restriction: production use requires a commercial license from Aurelianware, Inc.

Key points:

  • Source-available, not open source — you can read, modify, and build the entire codebase
  • Free for non-production use — development, evaluation, sandbox, training, and pre-production testing require no license
  • Commercial license for production — any environment processing real member data or supporting live operations requires a paid license
  • Automatic conversion to Apache 2.0 on March 8, 2030 — at that point all production use restrictions are permanently removed, guaranteeing long-term availability regardless of Aurelianware's business continuity

What Is Free

No license key, registration, or approval required

You may use Cloud Health Office at no cost for all of the following purposes. Clone the repo, run bash ./scripts/deploy-local.sh, and build whatever you need.

  • Development — build, modify, and test locally or in CI/CD
  • Evaluation — assess the platform for your organization with no trial expiration
  • Sandbox environments — demo instances with synthetic or test data
  • Training and education — internal training, workshops, hackathons
  • Pre-production testing — staging, QA, integration testing
  • Contributing — submit PRs, file issues, improve documentation

What Requires a Commercial License

A commercial license is required when Cloud Health Office is used in a production environment — meaning any system that:

  • Processes real member or patient data (PHI/PII)
  • Supports live claims adjudication, payment, or billing operations
  • Generates revenue directly or indirectly
  • Is used by end users (members, providers, plan staff) in a production capacity
  • Runs as part of a commercial SaaS or managed service offering

FAQ

Can I use this in development for free?

Yes. Development, testing, and evaluation use is free with no restrictions. Clone the repo, run bash ./scripts/deploy-local.sh, and build whatever you need.

Can I run this in a sandbox?

Yes. Sandbox and demo environments with synthetic or test data are free. This includes internal demos, POCs, and pre-sales environments.

Do I need a paid license for production?

Yes. Any environment processing real member data, live claims, or supporting production operations requires a commercial license.

What about evaluation with synthetic data?

Free. You can evaluate the full platform with synthetic data for as long as you need. There is no trial expiration.

How do I ask about enterprise licensing?

Contact us at licensing@cloudhealthoffice.com. We respond to licensing inquiries within one business day.
