Overview 
Background 
The X12 standard 278 transaction, Healthcare Services Review —Request for Review and Response 
(X217) , allows providers to request authorizations, referrals, and certifications  and allows payers to 
respon d to these requests . This transaction differs from  Healthcare Services Review —Inquiry and 
Response (X215), for which you must complete a similar  questionnaire if you are also implementing that  
transaction.  
Availity has approved the specifications outlined in this document to ensure a timely and successful 
implementation with all clients. If your system is unable to support these  specifications, please speak with 
your assigned Availity implementation contacts regarding additional options.  
For some Utilization Management (UM) systems, Availity has developed APIs to support the authorization 
process . Direct connection between Availity and the payer’s UM system is an option. If your current EDI 
gateway or UM tool does not support the X12 278 standards, please discuss  options with the 
implementation team . Note that Availity does not support direct integration with multiple UM systems for a 
single payer. While Availity does support standard integration, deviating from the standard results in 
additional Statements of Work and expanded timeline . Please discuss any deviations from our standard 
implementation  with the implementation team .  
Audience 
Due to the wide range of questions asked, this questionnaire should be completed by various members of 
your implementation team, including project management , business owners  and technical architects.  
External documentation 
X12 implementation guides  
The X12 Implementation Guides contains  rules for format, content, and data element values for this 
transaction. These are listed in the ASC X12 Technical Report Type 3 (TR3): Health Care Services 
Review — Request for Review and Response (278) ; version/release/industry identifier code: 
005010X21 7. 
This document is not a companion guide for the 278 transaction and does not  convey information that 
exceeds the requirements or usages of data expressed in the TR3.  
The TR3, also known as X12N Implementation Guide (IG), adopted under HIPAA, will be referred to as the IG or TR3  in this document . 
For more information, please refer to the appropriate X12 TR3 for any transaction you are submitting. For 
a cost, you can obtain a TR3 from the publisher, X12 (https://x12.org/products/glass ). X
12 offers 
implementation guides for each transaction type in a regular version and a combined version, which contains the addenda.  
External code sources  
For information on external code s ets referenced in this document , refer to  x12.org/codes  and Appendix A 
in the 005010X217 TR3.
